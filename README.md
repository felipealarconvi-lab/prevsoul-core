# Prevsoul Core

Plugin de WordPress de prevsoul.cl: odontólogos, clínicas, Prevsoul Live, sala de espera, productos por categoría, buscador de necesidades, diseño completo y modo «Estamos restaurando».

Las versiones se publican como *releases* con el archivo `prevsoul-core.zip`; el sitio las detecta y se actualiza solo.
